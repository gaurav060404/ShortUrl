# Short URL 

A React & Express App for Short URL - which allows you to short your long urls into short urls with ease.

## Tech Stack

**Frontend**
- React (Vite)
- Axios (HTTP Request)
- React Router Dom (For Client Side Routing)
- Tailwind CSS (Styling)

**Backend**
- Express.js 
- Mongoose
